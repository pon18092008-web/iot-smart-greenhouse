# Умная теплица IoT (IoT Smart Greenhouse)

Учебный прототип веб-платформы мониторинга и управления теплицей: датчики, автоматический полив с защитой насоса, вентиляция, обогрев, досветка, тревоги, журнал событий и Smart Analytics.

**Автор:** Эсенканов Н.А., группа КС-1-24

**Проверил:** Каныбеков К.К.

## Возможности

| Страница | Что умеет |
|---|---|
| Стартовая (`index.html`) | Схема теплицы с живыми показаниями |
| Панель управления (`dashboard.html`) | 6 KPI, карточки зон с risk score, графики, последние тревоги и события |
| Зоны (`zones.html`) | 3 зоны (Томаты, Огурцы, Зелень), поиск и фильтры, показания и пороги |
| Датчики (`sensors.html`) | 18 датчиков 6 типов, состояние «в сети / не в сети», время обновления |
| Управление (`control.html`) | Режимы АВТО / РУЧНОЙ, 6 устройств, долив воды, тестовые сценарии |
| Тревоги и журнал (`alerts.html`) | Тревоги «Внимание / Критично», журнал событий, фильтры, экспорт CSV |
| Аналитика (`analytics.html`) | Risk score, резкие изменения ≥ 30%, рекомендации |
| Настройки (`settings.html`) | Пороги каждой зоны, скорость симуляции, тема, сброс данных |

## Как это работает

- **Симулятор** (`simulator.js`) каждые 3–10 секунд формирует новый замер. Показания зависят от устройств: насос увлажняет почву и расходует воду, вентилятор охлаждает, фитолампа добавляет света.
- **Автоматика** (`automation.js`) в режиме АВТО сравнивает показания с порогами зоны и управляет насосом, вентилятором, обогревателем, фитолампой, увлажнителем и форточкой. Используется **гистерезис**, чтобы устройства не переключались на каждом замере.
- **Защита насоса:** при уровне воды ≤ критического насос не включается, создаётся критическая тревога.
- **Smart Analytics:** risk score 0–100, поиск резких изменений, рекомендации в формате «что произошло → почему важно → что сделать». Без платных AI-сервисов.
- Все данные (зоны, датчики, пороги, тревоги, журнал, история) хранятся в `localStorage`.

## Запуск

Откройте ссылку GitHub Pages или запустите локальный сервер в папке проекта:

```
python3 -m http.server 8000
```

и перейдите на `http://localhost:8000`.
